# Bonbon d'agneau

**Catégorie :** Base — garniture

---

## Ingrédients

| Quantité | Ingrédient |
|----------|------------|
| QS | Collier d'agneau |
| QS | Garniture aromatique (carotte, oignon, ail) |
| QS | Persil plat haché |
| PM | Sel |
| PM | Poivre |

---

## Procédé

1. Cuire les colliers avec la garniture aromatique (carotte, oignon, ail).
2. Effilocher.
3. Assaisonner avec le jus de cuisson réduit à glace.
4. Ajouter le persil plat haché.
5. Rectifier sel et poivre.
